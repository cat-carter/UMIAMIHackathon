Short Description:

Breeze Book is an AI-powered hotel event space marketplace that connects businesses with the right venues. Hotels can showcase their spaces through immersive 360° tours and interactive floor plans, while AI-powered matching helps planners discover venues based on their event needs, budget, location, and style. Turn spaces into opportunities and make booking a breeze.


Tools used: claude, ChatGPT, Cursor, Copliot
