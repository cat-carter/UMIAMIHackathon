# Test images for Search by photo

Upload any of these on the BreezeBook page (Search by photo → Upload a photo) to try the photo matcher.
They are cropped and mirrored versions, so they are not the exact images the matcher was taught with.

| File | Expected match |
|---|---|
| judge_test_1_grand_ballroom.jpg | The Grand Ballroom |
| judge_test_2_event_hall.jpg | Event and convention halls |
| judge_test_3_rooftop.jpg | Rooftops |
| judge_test_4_courtyard.jpg | Gardens and courtyards |

The matcher compares color, light and layout with reference photos in the page itself. It runs in the browser, sends nothing
anywhere, and reads the look of a room, not its size, so check capacity on each space it suggests.
